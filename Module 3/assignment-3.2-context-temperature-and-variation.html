AI Literacy · Module 3 · Assignment 3.2

Context, Temperature, and Variation — Individual Submission

Submit in CanvasIndividual workHands-on with an LLM

Purpose: Run two controlled experiments on a real language model. In the first, you change only the context you give it. In the second, you change only the model’s own settings, such as temperature. Then explain which change produced which difference in the output.
Learning target: Analyze how context, instructions, and variation affect generative outputs.

What to submit

  1. A run log for both experiments: the exact prompt, every setting, and the full output for each run.
  2. A comparison of the outputs for each experiment (150–250 words each), tied to specific quoted evidence from your run log.
  3. A short reflection answering: What changed across the outputs, and which changed condition best explains the difference?
  4. An AI-use disclosure using the form below.

Before you start: pick one task

Use the same task in both experiments so you can compare across them. It should have a creative part (so outputs can differ) and a factual part (so you can check them). Use the default task below, or write one of your own with both parts.

Default task: “Explain how photosynthesis works to a sixth grader in about 120 words. Include one analogy and one specific fact (a number, name, or date).”

Directions

Experiment A — Change only the context

Open the LLM platform (Arthur Live). Record the model name and its current settings, then leave every setting unchanged for all three runs. Start a new, empty chat for each run so earlier runs don’t leak into later ones.

RunWhat you give the model
A1 — No contextThe bare task only.
A2 — Added contextThe same task plus context you write: who the reader is, what they already know, and the tone you want.
A3 — Provided sourceThe same task plus a short passage (3–6 sentences) from a source you chose and cite, with the instruction to use only that passage.

Experiment B — Change only the model settings

Now use one fixed prompt (the bare task from A1) and change only the model’s settings. Start a new chat for each run, and record each setting exactly as you set it.

RunSettings
B1 — Low temperatureSet temperature to its lowest or near-lowest value (for example, 0 to 0.2).
B2 — Low temperature, run againThe identical settings as B1, and a fresh chat. This shows whether the same settings give the same output.
B3 — High temperatureSet temperature to its highest or near-highest value that still gives readable output.
B4 — High temperature, run againThe identical settings as B3, and a fresh chat.

Optional stretch: if the platform offers other controls (for example top-p, maximum length, or a system prompt), pick one, change only that, and add it as run B5 with a short explanation.

If a setting isn’t available: Platforms differ. Use whichever of temperature, top-p, or maximum length your platform actually exposes, and name it in your log. If it exposes none of them, do Experiment A and, for B, run the identical prompt four times on the same settings and describe the natural variation you see. Tell your teacher which setting was missing; this is not a penalty.

Analyze and write

  1. Log your runs. For every run, paste the prompt, the settings, and the complete output. Screenshots are welcome as additional evidence but do not replace the pasted text.
  2. Compare Experiment A. Quote at least two specific passages that differ. Describe what the added context or source changed: length, tone, accuracy, specificity, anything that was invented. Which run followed the instructions best, and how do you know?
  3. Compare Experiment B. Compare B1 with B2, then B3 with B4, then low with high. What stayed the same when settings were identical? What changed when settings changed? Did higher temperature make the output more creative, less accurate, or both?
  4. Check the facts. Take the factual claim (or number, name, or date) from at least three different runs and verify it against a credible source you open yourself. Record whether each claim was correct, and whether a run’s confidence matched its accuracy.
  5. Reflect. Answer the reflection question. Then add one practical implication: when would you want low temperature, high temperature, or added context in real schoolwork, and why?

AI-use disclosure (required)

Using the approved LLM platform for these experiments is required, and the outputs belong in your run log. All of the analysis, comparison, and reflection must be your own writing. Do not ask an AI to write or polish your comparisons.

At the end of your submission, include:

  • Tool(s) used: the platform and the model name and version.
  • Settings: the settings you changed and the values you used.
  • Purpose: experiment runs, plus anything else you used AI for.
  • What you accepted, revised, or rejected: explain your decision about any output you used as evidence or examples.
  • Verification: identify the sources or checks you used for each factual claim.

Success criteria

  • Each experiment changes one variable at a time, and the run log shows exactly what changed.
  • Comparisons quote specific evidence from the outputs and do not claim certainty beyond the evidence. Four runs show a pattern, not a proof.
  • At least three factual claims are verified against sources you opened yourself.
  • The reflection explains a practical implication and identifies which condition best explains the difference.
  • Writing is organized, specific, and understandable to a reader who did not complete the activity. AI use is disclosed accurately and you remain responsible for the final submission.
