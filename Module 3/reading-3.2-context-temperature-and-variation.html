Context, Temperature, and Variation

Estimated time: 25–35 minutesRead independently

Essential question: Why can one prompt produce different answers at different times or settings?
By the end: Analyze how context, instructions, and variation affect generative outputs.

Begin with a prediction

Before reading, write two sentences: If you send the same prompt to a language model twice, would you expect identical answers? What would you change to make the answers more alike, or more different?

Core idea

A language model produces text one small piece at a time. At each step it works out how likely each possible next piece is, then chooses one. Two things shape the answer you get: what the model is given to work from, and how it makes that choice. Both are things you can see and change. Fluent output, however, is not a guarantee of accuracy, evidence, authorship, or understanding. Responsible work begins by separating what a system produces from what you can justify.

Two kinds of things you can change

1. The input (context and instructions)

The model only “sees” what is in the conversation: your instructions, any background or examples you add, any source text you paste in, and earlier messages in the same chat. A new chat starts with none of that. More specific context narrows the likely answers. It does not make them correct.

2. The settings (how it chooses)

Temperature controls how adventurous the choice is. At a low value the model almost always picks its likeliest next piece, so answers are more alike from run to run. At a high value less likely pieces get picked more often, so answers vary more and can drift. Other controls work similarly: top-p limits the pool of candidate pieces, and a maximum length cuts the answer off.

How to reason carefully

1. Change one thing at a time

If you change the prompt and the temperature together, you cannot say which one caused the difference. A controlled experiment changes one variable and logs everything else as fixed.

2. Repeat before you conclude

One output can differ from another by chance. Run identical settings more than once to see how much variation is normal before you claim that a change caused a difference.

3. Inspect the evidence

Ask where a factual claim came from. A citation is a lead, not proof, until you open the source and check whether it supports the exact statement.

4. Retain judgment

Decide what to accept, revise, narrow, or reject. You remain responsible for claims published under your name.

Worked example

Suppose you ask for a short explanation of photosynthesis and get a pleasing analogy plus the sentence “Plants use about 40 percent of sunlight to make sugar.” You rerun the identical prompt at a low temperature and get nearly the same text. You rerun it at a high temperature and get a livelier analogy, but a different number. Careful reasoning does not stop at “high temperature made it creative.” It asks: Which of the two numbers, if either, does a credible source support? Did the lower temperature make the first answer right, or only more repeatable? What would a second high-temperature run show?

Common misconceptions

Misconception: “Low temperature makes the model accurate,” or “If it gives the same answer every time, the answer is true.”
Correction: Low temperature makes output more repeatable, not more correct. A model can repeat the same mistake every time. Verification requires opening and evaluating a source.
Misconception: “Adding more context always improves the answer.”
Correction: Context steers the answer toward what you supplied. If the context is wrong, vague, or contradictory, the answer can follow it there. Even a source you paste in must be checked.

Purposeful interaction

Use the LLM platform to run the same short task twice with identical settings, then once with a higher temperature. Copy all three outputs and mark where they differ.

Afterward, write: What changed across the outputs, and which changed condition best explains the difference? What would you need to run again before you were confident?

Key vocabulary

TermStudent-friendly meaning
ContextEverything the model has in view when it answers: instructions, examples, pasted sources, and earlier messages in the chat.
TemperatureA setting for how much the model sticks to its likeliest next pieces. Low is more repeatable; high is more varied.
Top-pA setting that limits how many of the likeliest next pieces the model may choose from.
Controlled experimentA test that changes one variable and keeps everything else the same, so the cause of a difference can be identified.
GroundingConnecting an answer to reliable, inspectable sources or provided evidence.
HallucinationA confident-sounding output that is unsupported, false, or invented.
VerificationChecking a claim against credible evidence, not merely trusting its presentation.
AuthorshipResponsible ownership of the choices, claims, evidence, and final form of work.
