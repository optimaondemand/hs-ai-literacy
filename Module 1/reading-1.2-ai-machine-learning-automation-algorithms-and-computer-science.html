Names, Categories, and Claims About AI

Reading before the lesson activity

Estimated time
15–20 minutes
Focus question
How do AI, machine learning, automation, algorithms, and computer science relate without becoming synonyms?
Required for
Lesson 1.2: Concept Map

Begin with a prediction. Which term seems broadest: computer science, AI, machine learning, automation, or algorithm? Which two terms do people most often blur together? Keep your prediction in mind.

Why names matter

“AI” is often used as a compliment, a warning, or a shortcut for anything complicated. A label is useful only when it helps us describe what a system actually does. If every automated tool is called AI, the word tells us very little. If AI means only a human-like machine, we overlook many systems that already influence daily life.

This course uses a vocabulary map rather than a stack of synonyms. A system can fit more than one category. Your job is to identify the labels supported by evidence—not to award or deny a buzzword.

The broad field: computer science

Computer science is the study of computation: what can be calculated, how information can be represented and processed, how algorithms work, and how software and hardware systems can be designed. Building a website, encrypting a message, sorting a list, or designing a database may involve computer science without involving AI.

Algorithms and automation

An algorithm is a defined set of steps for solving a problem or completing a task. A recipe can be algorithm-like, although a computer algorithm is specified precisely enough for a machine to execute.

Automation occurs when a system carries out a process with little ongoing human intervention. A schedule that turns lights off at 10:00 p.m. is automation. Automation can be simple or sophisticated; it does not require machine learning.

AI and machine learning

Artificial intelligence (AI) is a broad field concerned with systems that perform tasks associated with perception, language use, learning, reasoning, planning, or decision-making. AI includes several approaches. Some systems use hand-written rules; some search through possibilities; some learn patterns from data.

Machine learning (ML) is an approach within AI in which a system learns patterns from examples or data rather than relying only on rules written in advance. A spam filter may learn from examples of wanted and unwanted messages. A recommendation system may learn statistical patterns from users’ behavior. ML is inside AI, but AI is not limited to ML.

A map, not a yes/no test

TermWhat it helps describeExample
Computer scienceThe broad academic field of computation and computing systemsDesigning a secure database
AlgorithmDefined steps for a taskSorting names alphabetically
AutomationA process performed with little ongoing interventionA timer-controlled light
AISystems aimed at intelligent-seeming tasksA route planner or image recognizer
MLLearning patterns from data or examplesA spam filter trained on labeled messages

A recommendation system can be software, use algorithms, automate suggestions, use AI, and use ML. A timer-controlled light uses an algorithm and automation, but the example gives no evidence of ML. The strongest question is: Which descriptions accurately explain what this system does?

Careful claim move: Replace “This product is AI-powered” with a description of data, task, output, and evidence. For example: “The app appears to rank videos using patterns in viewing behavior; the company describes this as machine learning.”

Key vocabulary

  • computer science: study of computation, information, algorithms, and computing systems.
  • algorithm: defined steps for completing a task or solving a problem.
  • automation: carrying out a process with little ongoing human intervention.
  • artificial intelligence: a broad field for systems that perform tasks associated with perception, language, learning, reasoning, planning, or decision-making.
  • machine learning: an AI approach in which systems learn patterns from data or examples.
