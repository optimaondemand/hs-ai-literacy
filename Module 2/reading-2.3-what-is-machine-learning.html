Lesson 2.3: Learning-Approach Match

Begin with a prediction. A school wants to sort messages as urgent or routine, group anonymous survey responses by similarity, train a game-playing system through rewards, and adapt an existing image model to recognize local plants. Which tasks seem alike, and which need different approaches?

Machine learning finds patterns for a task

Machine learning uses data, examples, or feedback to adjust a model so that it performs a task such as classification, prediction, grouping, recommendation, or generation. Learning is not magic and it is not one single method. Different problems provide different kinds of information.

Supervised learning: examples and targets

In supervised learning, each training example includes a target: an image tagged “oak” or “maple,” a message labeled “spam” or “not spam,” or a home record paired with a past sale price. The model adjusts to reduce error on examples. The labels matter: if labels are inconsistent, narrow, or unjust, learning may reproduce those choices.

Unsupervised learning: structure without answers

Unsupervised methods search for patterns without being given a correct answer for each item. They can form clusters, compress representations, or flag unusual cases. A cluster is not a discovery of natural truth by itself; people must interpret whether the grouping is useful, misleading, or ethically appropriate.

Reinforcement and transfer

Reinforcement learning uses feedback over sequences: an action leads to an outcome and a reward signal. The system learns strategies that tend to earn reward. What is rewarded becomes crucial. Transfer learning starts with a model trained elsewhere and adapts it to a related task. It can save resources, but inherited assumptions and limitations still matter.

Approach-selection habit: Begin with the task, available evidence, error costs, and limits—not with a fashionable method. Explain why an approach fits and what could go wrong.

Key vocabulary

  • supervised learning: learning from examples paired with target labels or values.
  • unsupervised learning: finding structure in examples without target labels.
  • reinforcement learning: learning through actions and reward/penalty feedback.
  • transfer learning: adapting prior learning to a related task.
  • training example: an example used to adjust a model.
