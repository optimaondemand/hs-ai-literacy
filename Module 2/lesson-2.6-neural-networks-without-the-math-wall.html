Neural-Network Analogy and Limits
Module project
Explain a possible model carefully

Today’s Focus Question: How can we explain neural networks accurately enough to learn from them without turning metaphors into false claims?

Objectives

  • Define feature, weight, layer, activation, and decision boundary.
  • Describe how changing weights can change a classification boundary.
  • Create an analogy and identify where it fails.

Materials: Reading 2.6 and Canvas text-entry access. No external tool is required.

1 Retrieve and predict — 5 minutes

Imagine a classifier uses two features: size and color intensity. Sketch or describe one way a boundary could separate two categories. What happens if new examples have a color pattern not seen in training?

2 Experience: adjustable visual classifier — 10 minutes

Use the following text graph activity. Consider points described by two features: small/red, large/red, small/blue, large/blue. First sort by color only; then sort by size only; then imagine a boundary using both. Which training pattern could cause a shortcut?

Accessible text fallback: Make a 2×2 table with size and color. Mark a proposed category for each cell. Then write how a new purple or medium-size item might challenge your rule.

Feedback check: A decision boundary is not a physical line inside the world. It is a mathematical separation in the representation the model uses.

3 Learn — 10 minutes

Read Reading 2.6. Create a five-term glossary and one “not the same as” note: neural network is not a brain; weight is not a human preference; output is not proof of understanding.

4 Practice with feedback — 8 minutes

Complete Guided Practice 2.6 in Canvas. It asks you to match terms, identify an analogy overreach, and explain a decision boundary.

5 Apply independently — 15 minutes

Open Assignment 2.6 — Neural-Network Analogy and Limits. Explain a neural network with an analogy, then identify two ways the analogy fails.

AI-use guidance: Do not use generative AI to draft the analogy or critique. You may use the reading.

6 Build the portfolio — 5 minutes

Write one sentence that could explain a limitation of your model without saying it “understands” or “knows.”

Success checklist

  • I can define the five technical terms in accessible language.
  • I can explain why a shortcut pattern can be risky.
  • I can separate a useful analogy from a literal claim.
  • I submitted the analogy and limits assignment.

AI Lab Notebook

Write 3–5 sentences: What does your analogy help explain, and where might it mislead a reader? Add disclosure.
