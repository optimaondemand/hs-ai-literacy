Lesson activity and guided application

Learning-Approach Match

Identify likely model approach

Today’s Focus Question: Which learning approach fits a problem, and what tradeoff follows from that choice?

Objectives

  • Define supervised, unsupervised, reinforcement, and transfer learning.
  • Match an approach to a problem using available information.
  • State one tradeoff or risk for each approach.

Materials: Reading 2.3 and Canvas text-entry access. No external tool or account is required.

1 Retrieve and predict — 5 minutes

For each task, choose a first-fit approach: classify labeled emails, group anonymous responses, teach a game agent using points, adapt a general image model to local plants. Write one reason for one choice.

2 Experience: decision-path simulation — 10 minutes

For four problems, answer: Do you have target labels? Do you want to discover structure? Is the task a sequence with rewards? Do you have a related pre-trained model? Use the answers to choose an approach.

Accessible text fallback: Use the four questions above as a decision table. For each problem, write the approach, evidence for fit, and one risk.

Feedback check: There can be more than one possible method. Full credit comes from explaining why one approach is a reasonable first choice and naming what it does not solve.

3 Learn — 10 minutes

Read Reading 2.3. Make a four-column note card: approach, what it receives, example task, tradeoff.

4 Practice with feedback — 8 minutes

Complete Guided Practice 2.3 in Canvas. It includes approach matching, labels versus rewards, and a question about interpreting clusters carefully.

5 Apply independently — 15 minutes

Open Assignment 2.3 — Learning-Approach Match. Match four problems to approaches and justify each choice in prose.

AI-use guidance: Do not use generative AI to draft your justifications. You may consult the reading while writing.

6 Build the portfolio — 5 minutes

For your possible model investigation, state whether it would need labeled examples, unlabelled patterns, reward feedback, or transfer from an existing model. It is acceptable to answer “not enough information yet.”

Success checklist

  • I can define all four learning approaches.
  • I can explain a fit using the information available.
  • I can name a tradeoff rather than claiming a method is automatically best.
  • I completed Guided Practice 2.3 and submitted the assignment.

AI Lab Notebook

Write 3–5 sentences: Which learning approach seems easiest to misuse, and what question would you ask before selecting it? Add your AI-use disclosure.
